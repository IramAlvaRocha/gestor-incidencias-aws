# Design Context

## Product
Arena — gestor de incidencias / tickets estilo Jira para equipos de desarrollo.

## Visual direction
- Dark-first, navy workspace (Atlassian-inspired, not purple)
- Electric blue accent for primary actions and active nav
- Collapsible left sidebar (icon + label), dense but readable
- Outfit for UI, JetBrains Mono for keys/codes
- Cards with subtle borders, hover lift, no heavy shadows
- Login: atmospheric full-bleed with brand-forward card

## Tone
Professional, calm, tool-like. Spanish UI copy.
